# EIKEN Pre-2 Interview A

英検準2級 二次試験 Picture A の練習用ブラウザ教材です。

- 全20問
- 画像を見て現在進行形の英文を入力
- API / AI接続なし
- 大文字小文字・句読点を吸収
- 許容表現を複数登録
- 軽いスペルミス、人物の取り違え、be動詞などをブラウザ内でフィードバック
- スマートフォン対応

## Files

- `index.html` UI
- `style.css` デザイン
- `app.js` 問題データ・判定ロジック
- `images/01.webp` 〜 `images/20.webp` 問題画像

## GitHub Pages

Pages を main ブランチ / root から公開すると、そのまま静的サイトとして利用できます。
